# Privacy Policy — LLM Second Brain Runtime

Effective date: November 27, 2026

LLM Second Brain Runtime is a private, single-user tool operated by its owner.

## Google Drive access

The application requests read-only Google Drive access. It retrieves only files explicitly allowlisted by the owner. It does not create, edit, delete, share, or change permissions on Google Drive files.

## Data use

Retrieved information is used only to verify and analyze the owner's authorized Second Brain sources. The application does not sell data, use it for advertising, or provide it to unrelated projects.

Selected source excerpts and integrity fingerprints may be stored in the owner's private local runtime database. OAuth credentials are kept in private environment secrets. Short-lived access tokens are held in memory and are not written to the runtime database.

If the owner explicitly enables a separately configured AI provider, selected excerpts may be sent to that provider for the requested analysis under that provider's privacy terms. This is disabled by default.

## Retention and deletion

The owner controls the runtime database and may delete stored mission data at any time. Google access can be revoked from the owner's Google Account permissions page.

Questions may be submitted through this repository.
