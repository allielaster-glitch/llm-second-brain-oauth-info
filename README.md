# LLM Second Brain Runtime

LLM Second Brain Runtime is a private, single-user assistant operated by its owner.

The application uses Google Drive read-only access to retrieve only explicitly allowlisted Second Brain source files. It cannot create, edit, delete, share, or change permissions on Drive files.

The runtime is supervised and does not automatically deploy software, approve actions, or access unrelated projects.
